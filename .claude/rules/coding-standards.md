# RedLine Coding Standards

Concrete, enforceable coding standards for the RedLine codebase. Every rule is verifiable.

---

## Rule 1: Python 3.10 Only

Use Python 3.10 language features. Do not use 3.11+ features.

**Forbidden 3.11+ features:**
- `tomllib` (use `tomli` third-party package instead)
- `Self` type hint from `typing` without `from __future__ import annotations`
- `ExceptionGroup` / `except*` syntax
- `TaskGroup` (asyncio — also forbidden for other reasons)

**Verify your environment:**

```bash
python --version  # Must be 3.10.x
```

---

## Rule 2: SQLAlchemy 2.0 Synchronous ORM

Use the SQLAlchemy 2.0 synchronous API everywhere.

**Correct model definition:**

```python
from sqlalchemy.orm import Mapped, mapped_column
from sqlalchemy import func, text
import uuid

class MyModel(Base):
    __tablename__ = "my_models"
    
    id: Mapped[uuid.UUID] = mapped_column(
        primary_key=True,
        server_default=func.gen_random_uuid()
    )
    name: Mapped[str] = mapped_column(nullable=False)
    value: Mapped[Optional[float]] = mapped_column(nullable=True)
    created_at: Mapped[datetime] = mapped_column(
        nullable=False,
        server_default=func.now()
    )
```

**Never:**
- `Column(UUID, primary_key=True)` — use `mapped_column` (SQLAlchemy 2.0 style)
- `AsyncSession` — use `Session`
- `await db.execute(...)` — use `db.execute(...)` synchronously
- `session.query(MyModel).filter(...)` — use `select(MyModel).where(...)` with `db.execute()`

**Correct query pattern:**

```python
from sqlalchemy import select

# Correct — SQLAlchemy 2.0
result = db.execute(select(MyModel).where(MyModel.id == my_id)).scalar_one_or_none()

# Wrong — SQLAlchemy 1.x legacy
result = db.query(MyModel).filter(MyModel.id == my_id).first()
```

## Rule 3: Pydantic v2 API

Use Pydantic v2 API. Do not use v1 compatibility layer.

**Correct:**

```python
from pydantic import BaseModel, model_validator

class MySchema(BaseModel):
    name: str
    value: float
    
    @model_validator(mode="before")
    @classmethod
    def validate_all(cls, data):
        return data

# Load from ORM object (v2)
schema = MySchema.model_validate(orm_obj)

# Load from dict (v2)
schema = MySchema.model_validate({"name": "test", "value": 1.0})
```

**Never:**

```python
# v1 API — forbidden
schema = MySchema.from_orm(orm_obj)
schema = MySchema.parse_obj(data)
schema.dict()  # Use schema.model_dump() instead
schema.json()  # Use schema.model_dump_json() instead
```

## Rule 4: UUID Primary Keys with Server Default

Every DB model must use UUID PKs generated by Postgres (not Python `uuid.uuid4()`).

```python
# Required pattern
id: Mapped[uuid.UUID] = mapped_column(
    primary_key=True,
    server_default=func.gen_random_uuid()
)
```

**Why server_default, not Python default:** Ensures PK generation works in raw SQL scripts, seeds, and migrations without Python code — the DB is the source of truth.

## Rule 5: All FastAPI Endpoints Have `response_model`

Every FastAPI endpoint decorator must specify `response_model`:

```python
@router.post("/eval-runs", response_model=EvalRunResponse, status_code=201)
def create_eval_run(body: EvalRunCreate, auth: AuthContext = Depends(require_api_key)):
    ...
```

**Never:**

```python
# Missing response_model — FastAPI returns untyped JSON
@router.post("/eval-runs")
def create_eval_run(...):
    ...
```

All response models are `pydantic.BaseModel` subclasses defined in `apps/api/schemas/`.

## Rule 6: Scorers Return `ScorerResult`, Never Raw Booleans

```python
from apps.api.services.scorers.base import ScorerResult

class MyScorer:
    def score(self, case, transcript) -> ScorerResult:
        passed = ...  # bool
        detail = ...  # str explaining why
        return ScorerResult(passed=passed, detail=detail)
        
        # NEVER:
        # return passed  # raw bool
        # return {"passed": passed}  # raw dict
```

## Rule 7: Test Markers Are Required

**Unit tests** — at the top of every unit test file:

```python
import pytest
pytestmark = pytest.mark.unit
```

**Integration tests** — at the top of every integration test file:

```python
import pytest
pytestmark = pytest.mark.integration
```

A test file without `pytestmark` will not be picked up by `pytest -m unit` or `pytest -m integration`.

## Rule 8: Never Use `prometheus-fastapi-instrumentator`

This package requires `starlette>=1.0.0`. FastAPI 0.115.6 ships with `starlette==0.41.x`. The conflict causes an import error at startup.

**Use `prometheus-client 0.21.1` directly:**

```python
# apps/api/core/telemetry.py
from prometheus_client import Counter, Histogram, generate_latest, CONTENT_TYPE_LATEST

EVAL_RUNS_TOTAL = Counter("eval_runs_total", "Total eval runs", ["status"])
EVAL_CASE_COST_USD = Histogram("eval_case_cost_usd", "Cost per eval case in USD")
```

Expose metrics on `/metrics` endpoint manually:

```python
from fastapi import Response
from prometheus_client import generate_latest, CONTENT_TYPE_LATEST

@app.get("/metrics")
def metrics():
    return Response(generate_latest(), media_type=CONTENT_TYPE_LATEST)
```

## Rule 9: Import Order

Imports must be in this order, separated by blank lines:

```python
# 1. Standard library
import uuid
import hashlib
from datetime import datetime
from typing import Optional

# 2. Third-party packages
import httpx
from fastapi import APIRouter, Depends
from sqlalchemy.orm import Session

# 3. Internal — core layer first

from apps.api.models.eval import EvalRun, EvalCase
```

## Rule 10: Content Hash Computation

Agent version content hashes are SHA256 of the source file bytes. Always use:

```python
import hashlib

def compute_content_hash(file_path: str) -> str:
    with open(file_path, "rb") as f:
        return hashlib.sha256(f.read()).hexdigest()
```

**Never:**
- `hashlib.md5(...)` — too weak, collisions possible
- `hashlib.sha256(content.encode())` — encoding-dependent, use raw bytes
- Including timestamps or random values in the hash input — hashes must be deterministic and reproducible

**Expected output:** 64-character lowercase hex string. Example: `842a7a049760e678715704267b94307ce0812ba43b15dbb3127891849f9f5280`

## Rule 11: Worker Session Management

Every worker that uses a SQLAlchemy Session must use `try/finally` with `db.close()`:

```python
from apps.api.core.db import SessionLocal

def process_job(job_id):
    db = SessionLocal()
    try:
        # ... use db ...
        db.commit()
    except Exception:
        db.rollback()
        raise
    finally:
        db.close()  # Always close — never let sessions leak
```

**After a worker updates a row and another function reads it in the same session:**

```python
db.expire(eval_run)  # Expire cached state
db.refresh(eval_run)  # Re-read from Postgres
```

This pattern is required when the worker updates `status` and then reads it back.

## Rule 12: Health Endpoints

Every service app must have a `/health` endpoint that:
1. Returns `{"status": "ok", "service": "<service-name>"}` when healthy
2. Makes a live DB query to verify Postgres connectivity
3. Returns `200 OK` on success, `503 Service Unavailable` on DB failure

```python
@app.get("/health")
def health(db: Session = Depends(get_db)):
    try:
        db.execute(text("SELECT 1"))
        return {"status": "ok", "service": "eval-service"}
    except Exception as e:
        raise HTTPException(status_code=503, detail=str(e))
```
